# 高考考什么？从规则开始了解它

> *知己知彼，百战不殆。*
> ——《孙子兵法·谋攻篇》

---

乐乐、蕊蕊：

上一篇我跟你们说了，高考是一场规则明确、边界清晰、可以提前准备的标准化考试。这篇咱们就把这个"规则"拆开来看看——它到底考什么、分怎么算、每科难在哪。

在进入具体内容之前，我想先跟你们认真聊一件事：**为什么要先搞清楚"高考考什么"？**

这个问题听起来有点多余——不就是备考吗，不都是六门课吗？但你们身边肯定会有不少同学，高三学了大半年，却从来没有系统想过"语文作文和文言文哪个更值钱""化学和生物的分到底是怎么算的""数学改了哪里、重点在哪里变了"——他们不是不努力，是在努力之前缺了一个关键的步骤：**先把地图看清楚，再出发。**

---

## 搞清楚"考什么"，能带来什么？

**第一：知道把时间花在哪里。**

备考最容易犯的错误，不是不努力，是"平均用力"——六门课每门都碰一碰，每门都没深入；每天都在学习，但结束了觉得什么都没抓住。

但高考六门课，每科内部的分值分布差距极大。语文全卷150分，光作文就60分；数学全卷150分，五道解答题合计77分，比另外14道题还多；英语150分，阅读理解和七选五合计50分，占全卷三分之一。

知道这些数字之后，你做选择就有依据了——同样花一小时，是继续练语文选择题，还是打磨一篇作文？是刷20道数学小题，还是反复研究2道解答题？答案不难想清楚。时间就这么多，你得让每一分钟花在刀刃上。

**第二：知道对手是谁。**

高考不是你和卷子过招，是你和同一批考生竞争。这对原始分科目（语文、数学、英语、物理）是隐形的，对赋分科目（化学、生物）则是明确写进规则里的。

化学和生物，你卷面考多少不重要，重要的是你在全省选了这门课的考生里排第几。这意味着什么？意味着你学化学的目的不是"把书上的东西全部掌握"，而是"比大多数人掌握得更好"。如果全省化学的平均水平是70分，你考75分，排名可能在前30%；如果平均水平是80分，你考75分，可能就到50%了。

搞清楚这个逻辑，你就不会再觉得"差不多会了就行"——"差不多"在等级赋分里，意味着你正在被别人甩开。

**第三：知道哪里是真正的难关，别被假困难吓到。**

有个常见现象：很多同学一提物理就觉得难，一看题目就打退堂鼓，但其实物理卷子里有7道单选题是基础题，前5道几乎每个认真学的人都能做对。真正难的，是后面计算题的最后一问——那才是分水岭。

如果你提前知道这张地图，就不会在还没开始做题的时候就觉得"物理我不行"，你会知道：前面的分我拿得到，后面的最后一问我能做多少算多少。这种心态调整，在考场上价值千金。

反过来，也有"被低估的难"。生物看起来好像背一背就行，但甘肃卷16道选择题从分子到生态全覆盖，加上非选题的专业术语要一字不差，实际上是六科里最需要"细"的一门。很多同学生物没好好准备，觉得"生物嘛随便看看"，结果一考出来发现丢了三四十分，已经晚了。

**第四：知道哪些是可以提前准备的，哪些需要长期积累。**

高考的六门课，有些内容是短期可以突破的，有些是必须长期积累的。

短期可突破的，比如：数学解答题的前几问、化学选择题的记忆类知识、物理实验题的常见电路设计——这些有规律可循，集中训练几周能看到效果。

必须长期积累的，比如：英语词汇和阅读理解（词汇量不是一周能堆起来的）、语文作文的思辨能力（不是背几个素材就能提升的）、物理的建模直觉（题做多了、模型见多了才有感觉）——这些急不来，但提前知道，你就能提前开始。

乐乐，你现在升高三，暑假就要着手准备一轮复习了——时间紧，更要把有限的精力用对地方。蕊蕊，你还有整整两年，这两年你要好好利用起来，提前布局，提前把地图研究清楚，等到高三开跑的时候，方向早已不是问题。

**第五：考试本身是一门学问，得单独研究。**

高考不只是考知识，它同时也是一场考试——规则、结构、时间节奏，是可以单独研究和应对的。甘肃2025年是第一次用新高考，数学改了题目结构（从22题变成19题，解答题从70分涨到77分），这个变化对考场时间分配影响很大；语文语用题从选择题改成了主观题，备考的练法就得跟着变……

不了解这些变化，你可能用旧的方法练新的考法，白费功夫。

当然，考试技巧、考场策略这些内容，咱们在后续专门聊。这篇先把最基础的"考什么"讲清楚——骨架搭稳了，以后每根肉都能放对位置。

## 先说大框架：3+1+2

你们俩都选了物化生，高考一共考六科，总分750分：

**"3"——全国统考，原始分计入。** 语文、数学、英语，每科150分。全国新课标II卷，教育部统一出题。

**"1"——首选科目，原始分计入。** 你们选的是物理，100分。甘肃省自己出题。

**"2"——再选科目，等级赋分计入。** 化学、生物，各100分。也是甘肃卷。但这两科的分不是卷面上考多少就记多少，要经过"等级赋分"换算，后面专门讲。

六科加起来：150×3 + 100 + 100×2 = **750分**。

## 六科的重难点：哪里是山，哪里是路

### 语文（150分，150分钟，6月7日上午）

卷子：**阅读72分 + 语用18分 + 作文60分**，23题。

语文的重难点不在"会不会"，在"稳不稳"。这门课最特殊的地方是——没有哪道题是"完全不会"的，但到处都是"以为自己会了其实没拿到分"的坑。

**作文60分，全卷最大的一座山。** 现在的作文是任务驱动型——给你一个具体情境，让你在情境里完成写作。它不是让你"围绕XX写一篇议论文"，而是把你放进一个角色里，有特定的对象、目的和场合。这意味着什么？**模板不好使了。** 你得真的能思考、能表达、能把道理说清楚。很多同学考前背了一堆"万能素材"，上了考场发现套不进去——因为情境不同，你生硬地塞进去，阅卷老师一眼就看出来了。

怎么准备？**多读、多想、多写，没有捷径。** 每周至少写一篇完整的作文，找人批改——不是批个分数，而是告诉你哪里逻辑断了、哪里说理空了、哪里没扣住情境。乐乐，你平时语言表达上不太表现，但写作恰恰需要你把自己的思考组织出来——不用写得多漂亮，把话说清楚、说完整就行。蕊蕊，你语言表达上比较开放，但也要再协作上多下功夫——练习的时候刻意练"扣题"，每段开头都回扣一下题目给你的情境。具体怎么改进，后面咱们再详细探讨。

**文言文+古诗+默写，35分，这是"稳"的根据地。** 文言文翻译要**字字落实**，不能只翻译大意——"之""其""而"这些虚词，每个都有对应的翻译。120个常考实词必须扎实掌握，不是大概知道意思就行，是每个词的几个义项都得记住。默写6分是全卷最该拿满的——每天早读10分钟反复滚动，错别字是最大杀手，"沧海"不能写成"苍海"，"长风破浪"不能写成"乘风破浪"。

**语用18分，看起来少，但2025年考法变了——成语题、病句题不再是选择题，改成你自己写、自己改。** 这意味着"蒙"的退路没了，你必须真会。这块是全卷最容易提分的板块，但也最容易被忽略——每周花10分钟做几组专项训练就够了，关键在坚持。

### 数学（150分，120分钟，6月7日下午）

卷子：**8单选 + 3多选 + 3填空 + 5解答**，19题。2024年改革后，解答题分值从70涨到了**77分**。

数学的重难点，一句话概括：**不是"不会做"，是"做不完整"。**

解答题77分，占全卷一半以上。最后一题17分，一道题的分值就超过全卷的10%——比3道单选题还多。但大多数同学的问题不是大题完全不会，而是——会做开头，做不完结尾。

**五道大题的难度梯度：**

- **第15题（13分）**：三角函数或数列，是五道大题里最"亲民"的。但"亲民"不等于"简单"——很多同学在这里轻敌，计算出错，丢了不该丢的分。这道题的目标不是"做出答案"，是**满分**。

- **第16题（15分）**：立体几何。建系+坐标法是通用解法，但前提是建系要建对——坐标建错了，后面全白算。这块的难点不在思路，在**空间想象+计算准确**。

- **第17题（15分）**：概率统计。这道题的特点是**题目长、信息多**，文字量可能是全卷之最。难点不在公式，在**审题**——从一大段文字里提取数学信息，漏看一个条件就全错。

- **第18题（17分）**：解析几何。计算量大、步骤多，一道题可能要算半页纸。难点是**计算耐力**——思路对但算错的人比比皆是。

- **第19题（17分）**：导数。这是数学的"天花板"。第一问求切线或单调区间，大多数同学能拿到；第二问的证明题，需要构造函数、放缩、分类讨论，综合性极强。**这道题的分水岭在第二问。**

怎么准备？**数学不是"刷题"刷出来的，是"想明白"想出来的。** 每道大题做完之后，花5分钟复盘：这道题考了什么知识点？卡在哪个步骤？有没有更简单的思路？只刷不复盘，做1000道跟做10道没区别。

乐乐，要注意做数学题不能闷头想，想不出来就卡在那——数学大题想超过15分钟没有进展就该求助了，必要时候有些思路确实需要别人点一下。蕊蕊，要注意计算不能粗心，解析几何这种"算半页纸"的题尤其要检查——列完方程先验一遍再往下算。

### 英语（150分，120分钟，6月8日下午）

卷子：**听力30 + 阅读50 + 语用30 + 写作40 = 150分**，67题。

英语的重难点可以用一个字概括：**读**。

**阅读+七选五 = 50分，占全卷三分之一。** 阅读每题2.5分——错4题就丢10分，比以前更贵了。阅读为什么难？不是文章看不懂，是**看懂了也选不对**。选项之间的差距越来越小，干扰项的设计越来越精——它不是在考你"认不认识这个词"，而是在考你"理不理解这句话在文中的逻辑关系"。很多同学单词全认识，选出来的答案就是不对，原因就在这里。

**写作40分，包括应用文写作15分和读后续写25分。读后续写25分，是新高考英语最大的变量。** 给你一篇英文故事的前半段，你续写后半段——既要合逻辑（续写不能跟原文矛盾），又要有好语言（不能通篇简单句），还要有情感张力（故事要有波澜，不能平铺直叙）。这不是背模板能解决的，它需要你**真的读过足够多的英文，对英语的叙事节奏有感觉**。就像你没听过音乐，是写不出好旋律的。

怎么准备？**两条腿走路：词汇是地基，阅读是楼房。** 词汇量不够，阅读就是猜；只背词汇不读文章，读到长难句还是断不开。乐乐蕊蕊，要注意如果词汇量不够扎实，词汇就得提前下手，做长线战斗，维克多词汇每天30个滚动复习，不能断——词汇断了，阅读就断了，阅读断了，英语就塌了。读后续写要的是精准的书面英语，不是流利的中式英语，平时多读英文原版短篇，培养语感。

### 物理（100分，75分钟，6月8日上午）

甘肃卷：**单选7题28分 + 多选3题15分 + 实验2题15分 + 计算3题42分**。

物理的重难点，不是公式记不住，是**不会建模**——看到一道题，不知道该把它翻译成什么物理过程。

计算题42分，占全卷42%。三道大题的难度递进明显：

- **第13题（10分）**：力学基础，一般考运动学或牛顿定律。这块的难点不在思路，在**过程分析**——很多题是多个物理过程连在一起的（先加速再减速、先受力再撤力），你得分段列方程，一段一段地解。过程分析不清楚，方程就列不对。

- **第14题（15分）**：电磁学综合。电场、磁场、电磁感应，经常是带电粒子在复合场中运动——这块的难点是**空间关系**，你得把三维的运动轨迹画成二维的平面图，画对了才看得懂。乐乐，你的空间感需要专门练，多画图，画错了擦了重画，不要只在脑子里想象。

- **第15题（17分）**：压轴题。这道题经常把力学和电磁学串在一起，综合性最强。但就像数学的导数题一样，**第一问4-5分是大多数同学能拿到的**，后面看能力。

实验题15分，一力一电。电学实验是很多同学的噩梦——不是实验原理不懂，是**电路设计**不会。分压法还是限流法？电流表内接还是外接？这些选择背后都有逻辑，不能死记。更常见的问题是**有效数字和单位写错**——在实际考试中，相当多的学生在实验题上因为答题不规范丢分。这不是不会，是不够认真。

怎么准备？**物理的核心能力是"翻译"——把文字翻译成物理模型，把模型翻译成方程。** 每做一道大题，先不要急着算，花2分钟画受力图/运动过程图/电路图，把"物理翻译"做对了，后面就是数学计算。

### 化学（100分，75分钟，6月9日上午）

甘肃卷：**选择题14道42分 + 非选择题4道58分**，选择题均为单选，每题3分。

化学的重难点，三个字：**碎、杂、活。**

**碎——知识点碎。** 化学不像物理有一条主线贯穿，它更像一本百科全书——元素周期律、化学反应原理、有机化学、实验操作、工艺流程……每个板块都有自己的体系，板块之间的关联不像物理那么紧密。很多同学学化学的感觉是"每一块都会一点，但哪一块都不扎实"。

**杂——综合性强。** 非选择题58分，每道14-15分，一道大题可能同时考反应原理、实验操作和计算——你不能只会某一类，你得**什么都会**，而且能在同一道题里切换。

**活——不能死记。** 化学有个最常见的误区：把方程式全背下来就万事大吉。远远不够。你得理解"为什么这个反应能发生、条件变了会怎样"——高考考的不是你背了多少方程式，而是你**能不能推断一个没见过的反应会怎么进行**。工艺流程题就是典型：给你一个陌生的工业生产流程，让你分析每一步的原理——这种题靠背诵是做不出来的。

怎么准备？**化学的备考关键是"织网"——把零碎的知识点织成一张网。** 每学完一个板块，花10分钟画一张知识结构图，把概念之间的关联理清楚。方程式不是"背"的，是"推导"的——理解了原理，方程式自然就记住了。乐乐蕊蕊，要注意如果背了方程式不一定能写对——练"自己写"，盖住答案自己推导，比看10遍有效。方程式的条件（加热、催化剂、可逆符号）不能只记产物，条件错=整道题错。

### 生物（100分，75分钟，6月9日下午）

甘肃卷：**选择题16道48分 + 非选择题5道52分**，选择题均为单选，每题3分。

生物的重难点，也是三个字：**广、细、准。**

**广——覆盖面广。** 16道选择题是你们所有科目里最多的，从分子到细胞到遗传到生态全覆盖。这意味着你不能有明显的知识盲区——一个模块完全不学，可能直接丢6-9分。

**细——概念辨析细。** 生物选择题最折磨人的地方是：四个选项看起来都对，或者看起来都错。比如"直接原因"和"根本原因"、"主要因素"和"重要因素"、"转录"和"翻译"——这些概念之间的差别，有时候就差一个字。审题时漏看了"不正确的是"三个字，3分就没了。

**准——专业术语必须精准。** 非选择题的主观题，答案不是"意思差不多就行"——不能把"样方法"写成"抽样法"，不能把"有丝分裂"写成"减数分裂"，不能把"主动运输"写成"协助扩散"。**一个词写错，整空零分。** 这是生物最"无情"的地方。

实验设计题是很多同学的弱项——不是不会做实验，是**不会用规范语言描述实验**。你得写清自变量、因变量、对照组、预期结果，少写一个要素就扣分。这块不能靠"感觉"，得按模板练。

怎么准备？**生物的备考关键是"精准"——每个概念都要精确到课本原文的表述。** 看书的时候不能只是"大概看懂了"，而是要能复述——合上书，能不能把光合作用的过程从头到尾说一遍？说不出来就是没记住。乐乐蕊蕊，要注意审题，选择题里"不正确的是"这种陷阱必须圈出来。要避免做题偏慢，生物选择题覆盖面广，平时训练要注意速度和准确率并重。

## 等级赋分：化学和生物的分数不是你考多少就算多少

这是新高考跟以前最大的不同之一，很多同学到填报志愿都没搞明白。

化学和生物，你卷面上考的分数叫"原始分"，但计入总分时，要先换成"等级赋分"。怎么换？按你在全省同选这门课的考生中的排名比例分等级：

| 等级 | 排名比例 | 赋分区间 |
|------|----------|----------|
| A | 前15% | 100-86 |
| B | 15%-50% | 85-71 |
| C | 50%-85% | 70-56 |
| D | 85%-98% | 55-41 |
| E | 98%-100% | 40-30 |

打个比方——你化学卷面考了82分，如果排在前15%到50%之间（B等级），而这个等级里原始分最高90最低75，赋分区间85到71，那你的赋分大概78分。比82少了4分。但如果你卷面考了60分排名却在B等级里，赋分可能反而比60高。

所以等级赋分的本质是：**你的对手不是卷子，是跟你选同一科的其他考生。** 你考多少分不重要，你排在哪里才重要。

这有一个很实际的启发：选物化生的人多，竞争大，但反过来——只要你能排到前15%，赋分就是86到100。**你不能有明显的知识盲区**——化学的"碎"和生物的"广"在这里尤其致命，一个模块完全不会，可能直接掉出A档。这两科的每一分都在"争排名"，比原始分科目更不能大意。

---

## 考试三天：知道节奏，心里有数

**第1天**（6月7日）：语文 + 数学——两门150分主科连考，强度最大。

**第2天**（6月8日）：物理 + 英语——物理75分钟节奏紧，英语听力开考就放、迟到进不了考场。

**第3天**（6月9日）：化学 + 生物——化学8点半就考，比前两天早半小时；生物下午5点才考，中间7个多小时。

第4天你们不考试，别人还在考，你们已经结束了。

关于考试三天怎么安排体力和心态，到时候专门聊。现在你们只需要知道这个节奏，别觉得高考还远——时间安排本身就是规则的一部分。

---

## 知道规则，然后怎么用？

知道了高考考什么、分怎么算、每科难在哪，这不是终点——这是起点。这些信息能帮你们做几件关键的事：

**一、把精力往值钱的地方倾斜。** 数学解答题77分、语文作文60分、物理计算题42分、英语阅读50分——这些是分值最集中的地方，也是提分空间最大的地方。就像赶路，同样的时间你翻过一座大山比在平地上走100步前进得多。不是平地不重要，是山翻不过去你就到不了终点。

今年这个暑假，一定要利用起来。乐乐，你暑假启动一轮复习的优先级：数学大题→语文作文→物理计算→英语阅读→化学非选→生物选择。蕊蕊，你高二同步的优先级：数学新课→英语词汇和阅读→物理化学新课→语文文言积累→生物巩固。

**二、知道自己容易在哪里丢分。** 每科的重难点也是最容易丢分的地方——数学算不完、物理建不对模、化学记不牢、生物写不准。知道哪里容易摔跤，才能提前修路。后面咱们针对具体问题想办法，但前提是——你们得先承认"我有这个问题"。

**三、理解等级赋分的逻辑，不能有短板。** 化学和生物是等级赋分，一个模块拉胯可能把整体排名拖下去。所以这两科不能只学自己喜欢的部分——有机化学有趣但你不能跳过反应原理，遗传学难但你不能只背结论。
