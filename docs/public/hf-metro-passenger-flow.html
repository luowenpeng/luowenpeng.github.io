数据说明

数据来源
微博 @合肥轨道交通（uid 5836845536）每日 08:00~09:00 前后发布的 「#客流日报# / #客流信息# / #客流播报#」正文。本页按 30 天一窗调用 searchProfile 时间窗检索、逐条解析入库，不经人工转录。
历史格式与单位（本管道的关键）
合肥这条线换过三代发布格式：2018 年正文先写累计「线网总客运量」、分号后才写当日值； 2019–2022 年多数只给线网总量，单位有 乘次 / 人次 / 万人次 / 万乘次 四种； 2023 年起才稳定给出总量 + 逐线数值。采集时以「日期紧邻线网客运量」锁定当日值， 排除累计总量、假期汇总、单月新高、跨年纪录与专题长文；早期原始计数统一除以 10000 换算为 万人次。少量折叠长微博做展开降级，但专题稿不作为每日序列收录。
统计口径
单位均为 万人次。「线网客流」取官方当日线网客运量，分线路只在官方列示时写入； 未列示留空、折线断开，不按 0 计。全量中有逐线数值 1514 天、 仅总量 977 天、8 线齐全 127 天。 有逐线数值的日期逐日校验「分线合计 = 总量」，3 天官方原文本身不自洽 （2023-05-15、2024-04-13、2024-05-06），按官方原值收录、不做平衡或修正。
覆盖区间
2018-01-03 ~ 2026-11-04，共 2491 天； 区间自然日 3228 天，缺 737 天（22.8%）。 起点不是运营起始日，而是微博检索索引与官方发布节奏共同决定的边界： 2018-05~2019-09、2022-11~2023-02 存在成片缺口，另有疫情停发与个别日期未发布。 缺口一律留空，不插值、不做平滑。最近 365 天收录 363/365 天，仅 2 个缺口。
线路口径变化
1、2 号线分线数值最早见于 2018-01-03；3/4/5 号线自 2023-03-06 起稳定列示； 8 号线首现 2024-12-26、6 号线首现 2025-12-26、7 号线首现 2026-07-01 （以上为数据首现日，与线路开通日接近但不完全等同）。2020–2022 年多数日期官方只发总量， 因此那一段的分线折线是断开的，不是漏抓。
自动更新
本机自动化每周一 20:00（北京时间）执行一次（与重庆 17:00、南京 18:00、郑州 19:00 错峰）， 默认回溯 14 天。检索接口需要登录态 Cookie，为避免把微博凭据上传成仓库密钥， 采集放在本机读取本地 Cookie 文件完成、再提交推送；云端只保留手动应急入口。 采集幂等，回溯窗口大于采集间隔，任一周失败下一周自动补回。数据文件由脚本生成，请勿手改。
